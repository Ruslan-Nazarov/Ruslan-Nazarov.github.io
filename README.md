# Персональный сайт Руслана Назарова

Простой статический сайт на GitHub Pages: серый фон, оранжевые акценты, удобный текст для чтения.

## Разделы

- Об авторе — биография и фотография.
- Контакты — электронная почта и публичные профили.
- Тезисы по физике — текущая страница главы; пока опубликован обзор.
- Алгоритм ИИ — описание исследования.
- Статьи — только уже перенесённые полные тексты.
- Книги — обложки, описания и ссылки на книжные сайты.
- Проекты — описания и доступные внешние ссылки.

Есть русская и английская версии. Тексты и существующие адреса сохранены. Старые статьи со ссылками на Medium доступны по прежним адресам, но не включены в новый раздел полных статей. Поиск находится внизу страницы.

## Работа с материалами

Материалы добавляем через Codex по выбору автора. При переносе статей сохраняем текст без изменений: адаптируем только оформление, изображения, формулы и вёрстку. Новые переводы и изменения содержания согласуются отдельно.

Тексты: `src/content/`. Общие сведения: `src/data/site.json`. Меню: `src/lib/navigation.mjs`. Основное оформление: `src/styles/simple.css`. Обложки: `public/images/books/` — оригинальные `logo.png` из публичных репозиториев `handbook_ai` и `handbook_Languages`, без изменений.

Для проектов ссылка на GitHub выводится только при наличии в данных. Отсутствие репозитория не мешает странице с описанием.

## Запуск

Требуется Node.js 24.

```powershell
npm ci
npm run dev
```

Русская версия: http://127.0.0.1:4321/ru/

```powershell
npm run check
npm test
npm run build
npm run preview -- --port 4321
npm run test:browser
```

`npm run build` создаёт статические файлы в `dist/` и проверяет внутренние ссылки. Существующий GitHub Actions публикует сайт при отправке в `main`. Локальные изменения сами по себе не публикуются.

Книги сохраняют CC BY-NC-ND 4.0. Проверочный файл Яндекса сохранён. Историческая документация: `docs/README-BEFORE-SIMPLIFICATION.md`.
