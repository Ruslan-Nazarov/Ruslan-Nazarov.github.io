Справка

«Сохранить» записывает изменения на этом компьютере. «Обновить предпросмотр» пересобирает локальный сайт. «Опубликовать на сайте» отправляет сохранённые изменения в GitHub и обновляет публичный сайт.

Для готового материала выберите «Готов к публикации». Для незавершённой правки опубликованного текста выберите «Новая редакция — ещё не готова»: сайт сохранит прежнюю полную версию. Черновики доступны в локальном предпросмотре. Разрешение на публикацию графа задаётся отдельно.
