# Схема текущего движка DialecticAI

Добавлена 1 ноября 2026 года на русскую и английскую страницы проекта, слот №18 `dialectic-ai-architecture`. Это HTML/CSS-схема, а не снимок программы или результат эксперимента. Компонент: `src/components/DialecticArchitecture.astro`; подключение: `src/components/Media.astro`. Как и схема papanda, она отображается при отсутствии привязанного изображения в слоте.

Источник — локальная копия `dialecticalai` на редакции `a8a910dbd008ebed768770669c6b43431fae2f34`, совпадающей с источником описания страницы. Прочитаны README, `docs/ARCHITECTURE.md` и описание текущего `dialectic_world`. [Документация на этой редакции](https://github.com/Ruslan-Nazarov/dialectic_ai/blob/a8a910dbd008ebed768770669c6b43431fae2f34/docs/ARCHITECTURE.md) доступна из самой схемы.

Схема передаёт шесть этапов построения, возможность ранней остановки, ограниченное по объёму описание для агента и пересмотр по зависимостям с сохранением прежних версий. Принятие полного пересмотра отделено от хранения частичного. Повторный ответ требует решения приложения. Проверка формата, связей и совместимости не представлена как подтверждение содержательной правильности.

Новые запуски моделей, сравнительные эксперименты и изменения исходного исследовательского проекта не выполнялись. Исторические результаты остаются отдельным разделом страницы. Необязательный кадр №16 не заменяется этой схемой.
