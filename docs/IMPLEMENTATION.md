# Implementation decisions and source boundaries

- Astro static output with React Flow on the graph routes only; other pages use small native browser scripts.
- Root site URL: `https://ruslan-nazarov.github.io/`, `base: "/"`. The two handbook links remain absolute external URLs. There are no handbook routes or copies in this checkout.
- Original repository was cloned, including both commits and main history, into `repository/` because its parent already contained the owner's brief. Development branch: `feat/research-website`. No remote writes.
- Verification file is retained at repository root. The `public/` copy matches the original Git blob and live public response byte-for-byte: SHA-256 `b3d4e1e9019f2382f049a0f9048833d83a82ef05f194e0236aa981e7881ad65b`. A specific `.gitattributes` rule preserves its LF bytes on every platform. Git converted the initial root Windows working copy to CRLF (`9e1adbd2ef8c5bd9abac36b5c0fdff56b453bd196cdf17908f6188046e82c33b`); that existing working file is left untouched. The build checks its canonical text and the exact public/dist bytes.
- Inspection of the original main branch and live root page found no Yandex Metrika code. The original live HTML is retained in `docs/original-live-root.html`. No analytics code was removed. Book analytics belong to their separate sites and are not changed.
- GitHub CLI is installed but not authenticated. The public repository and published pages can be read without authentication. Private Pages settings cannot be verified through the unauthenticated Pages API. No Settings, Actions, domains or permissions were changed.
- Every editable content record has one permanent ID, a shared slug, explicit `publish`, `ready_ru`, `ready_en`, and localized text fields. An incomplete revision can fall back to a previously released complete bilingual record in `src/data/published.json`. This snapshot contains only public records.
- Existing complete published content should be snapshotted with `npm run content:release` before beginning an incomplete revision. The local editor performs this before every save. A GitHub contributor must commit the snapshot before changing ready flags; the release documentation explains this.
- `publish: false` explicitly unpublishes; incomplete translation does not. An invalid schema blocks the build before Astro runs. An absent draft is never sent to the client, RSS or Pagefind.
- Six project descriptions and four research descriptions are editorial summaries grounded in the brief. They do not assert scientific efficacy or supply missing results. Project `active` describes current work, not hypothesis validity or release maturity.
- No fake dated journal events. The only initial dated historical reference is the thesis start, 2020-11-11. Target 2026-11-11 is displayed separately as a plan, not fed into the event timeline.
- Thesis working structure: (1) Introduction / dialectics / reconstruction before dialectics; (2) Mathematics; (3) History of physics / Einstein / dialectical physics; (4) Education; (5) Artificial intelligence. Chapter text has one data source for chapter pages and the complete-page view. Final content requires `editorialStatus: final`, nonempty RU/EN body and both readiness flags.
- Graph source is intentionally empty until the parser is connected. The demo is a separate public UI fixture based on the 2026-09-29 inventory from the supplied dialectic-parser skill. It is explicitly not approved research data and not a live export. Demonstration statuses/types are provisional; no derivation was invented.
- Real graph publication is an explicit server-side allowlist. `originalKey` and hidden predecessor IDs never enter browser props. Hidden ancestry is represented only by a boolean notice, never by a fabricated edge.
- Import rejects inconsistent edges, cycles, changed IDs, original-key conflicts and removed nodes pending manual reconciliation. It reports changes and preserves existing overrides. New override files always have `approvedForPublication: false`.
- Markdown allows ordinary formatting and LaTeX; HTML and unsafe links are sanitized before trusted KaTeX rendering. Raw scripts in authored text cannot run.
- Cloudflare analytics loads only with an actual configured token. Contact form supports a configured Formspree endpoint, explicit privacy acknowledgement, honeypot, timeout and success/failure state. The unconfigured site shows only the verified GitHub profile and an honest email placeholder.
- Local editor is a loopback-only development helper, protected against cross-origin writes and DNS rebinding. It never becomes part of `dist`. It shares `.pages.yml` field definitions; browser edits do not require changes to components.
- GitHub Actions deployment is deliberately manual (`workflow_dispatch`) with main-branch and `PUBLISH` checks. A push alone cannot publish this site.
